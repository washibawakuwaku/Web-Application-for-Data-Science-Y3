# Data

```
data/
├── raw/         # Snapshot exported from the database – treat as READ-ONLY
│   └── attendance_raw.csv
└── processed/   # Clean data created by: python -m analysis.make_dataset
    └── attendance_clean.csv
```

> **Rule:** the raw snapshot is read-only. Every cleaning / enrichment step is written
> in code (`analysis/make_dataset.py`) so anyone can rebuild `processed/` from `raw/`.

## Where the data comes from

Unlike a dataset downloaded from the internet, this project's data is **produced by the
system itself**: teachers record attendance in the app, it is stored in the Django
database (`backend_django/db.sqlite3`), and `python -m analysis.export_data` writes a
flat snapshot to `raw/attendance_raw.csv`. The included snapshot is generated by
`seed_demo` (24 students, 6 courses, ~8 weeks of realistic attendance).

## `raw/attendance_raw.csv` — one row per attendance record

| Column | Type | Description |
|---|---|---|
| `date` | date | Day of the class session (`YYYY-MM-DD`) |
| `student_code` | ID | Student ID, e.g. `S2026001` |
| `student_name` | text | Student full name |
| `class_name` | category | Class the student belongs to, e.g. `M1-A` |
| `subject_code` | category | Subject code, e.g. `PY` |
| `subject_name` | text | Subject name, e.g. `Python Programming` |
| `teacher_name` | text | Teacher who recorded the session (may be blank) |
| **`status`** | **category** | **`present` / `late` / `absent`** — the value we analyse |
| `remark` | text | Optional note (e.g. "sick") |

## `processed/attendance_clean.csv` — adds the features used by the notebooks

Same rows after cleaning (valid status only, real dates, de-duplicated), plus:

| Column | Type | Description |
|---|---|---|
| `weekday` | category | `Monday` … `Sunday` (for the weekday pattern) |
| `week_start` | date | Monday of that record's week (for weekly trends) |
| `month` | category | `YYYY-MM` (for monthly trends) |
| `is_present` / `is_late` / `is_absent` | 0/1 | One-hot of the status |
| `attended` | 0/1 | `1` if present **or** late (late counts as attended) |

## Dataset summary

| Item | Value |
|---|---|
| Source | The system's own database (seeded demo data) |
| Rows × columns (clean) | ≈ 984 × 16 |
| Target of analysis | `status` → attendance rate `(present + late) / total` |
| Known problems handled | invalid status, unparseable dates, duplicate (student, course, day) rows |
